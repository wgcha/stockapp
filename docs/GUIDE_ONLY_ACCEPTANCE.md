# 1단계 인수 기준: 가이드 중심 문답

일반 봇의 기본 설정을 대상으로 한다. 내부 모의주문 옵션을 켠 테스트는 별도 연구 회귀이며
이 인수 기준을 대체하지 않는다. 실제 Telegram 연결 검증은 4단계 승인 후 수행한다.

| 상황 | 기대 결과 |
| --- | --- |
| 도움말 / 시작 | 투자조건·보유·관심·가이드·자동 알림 예시와 직접 거래 안내 |
| 투자조건 저장 / 내 설정 | 참고 위험 조건을 보여주며 봇 주문 권한을 부여한다고 표시하지 않음 |
| 단일 종목 / 오늘 가이드 | 판단·근거·위험 조건 유지, 소유자 주문 승인 요구 없음 |
| 주문 005930 1주 70000원 / 005930 1주를 7만원에 사줘 | 증권사 앱에서 직접 거래 안내, 제안·승인코드·원장 체결 생성 없음 |
| 삼성전자 사줘 / 주문 취소해줘 | 매매 실행 대신 직접 거래 안내 |
| 승인 또는 거절 명령 | 기본 서비스에서는 주문 처리 없이 직접 거래 안내 |
| 매수해도 돼? 같은 질문 | 실행 명령으로 오인하지 않음; 지원 형식 밖이면 도움말로 안내 |
| 주문마다 승인 등이 포함된 투자조건 | 매매 실행 명령으로 오인하지 않고 조건 문답 처리 |
| 비허용 사용자 | 접근 거부, 가이드·주문 안내 및 정보 노출 없음 |
| 가이드 이후 매매 요청 | 최신 가이드 유무와 무관하게 기본 봇에서 제안·브로커 호출 없음 |
| 기존 내부 연구 테스트 | 모의 실행을 명시한 테스트에서만 연구 흐름 유지, 실제 주문은 계속 차단 |

자동 회귀 결과와 검수 결과는 CHANGELOG에 기록한다. 메시지 재시도·처리 ID 영속화,
휴장일 처리, 백업 복원은 이번 단계 완료를 이유로 구현완료로 표시하지 않는다.
